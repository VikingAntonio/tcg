# Protección de Datos y Seguridad (Supabase Auth)

Se ha implementado una migración completa a **Supabase Auth** para garantizar que los datos de los usuarios (especialmente las contraseñas) estén protegidos y no sean visibles en la consola del navegador.

## Cambios Realizados:

1.  **Autenticación Nativa**: Se eliminó el sistema de login manual. Ahora se utiliza `_supabase.auth` para manejar sesiones de forma segura.
2.  **Eliminación de select('*')**: Se refactorizaron todas las consultas al frontend para que solo soliciten las columnas necesarias y no sensibles.
3.  **Seguridad por Capas (RLS)**: Se han configurado Políticas de Seguridad a Nivel de Fila (RLS) que aseguran que:
    *   Cualquier usuario puede ver perfiles de tiendas y álbumes públicos (solo lectura).
    *   Solo el dueño de una cuenta puede modificar sus álbumes, páginas, decks y perfil.
    *   Las contraseñas ya no se guardan en la tabla `usuarios`, sino que las gestiona Supabase de forma encriptada.

## Instrucciones para el Administrador:

Para aplicar estos cambios en tu base de datos, debes ejecutar el script SQL que se encuentra en el archivo **`auth.txt`** en el Editor SQL de Supabase.

### NOTAS IMPORTANTES:

*   **Migración Destructiva**: El script en `auth.txt` borrará las tablas actuales para recrearlas con el formato de seguridad necesario (UUID). **Se perderán los datos actuales de usuarios y cartas.**
*   **Gestión de Usuarios**: Por seguridad, la creación manual de usuarios desde el panel de administración ha sido limitada. Se recomienda:
    1.  Que los usuarios se registren ellos mismos desde la página principal.
    2.  O bien, crearlos directamente desde el Dashboard de Supabase (sección Authentication).
*   **Login por Usuario**: El sistema utiliza un truco técnico para permitir el login con nombre de usuario (añadiendo un sufijo interno). Si un usuario cambia su correo electrónico desde el perfil, deberá usar su correo completo para iniciar sesión.

Esta actualización asegura que tu sitio web cumpla con los estándares modernos de seguridad y protege la privacidad de todos tus usuarios.
